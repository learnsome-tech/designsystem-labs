### Build a Fluid Typography and Spatial Token Suite

1. Define a modular typography scale using a Major Third ratio.
2. Compute a fluid CSS clamp formula between mobile and desktop sizes.
3. Establish an 8-point spatial scale for padding, margin, and gaps.
4. Assert that generated sizes maintain mathematical proportions.

> **Hint:** Use linear interpolation to compute the slope and rem offset.

## Check yourself

- What is a modular typography scale and what advantages does it offer over arbitrary font sizes?
- How does CSS clamp() enable fluid typography without media query breakpoints?
- Why is the 8-point spatial grid the industry standard for UI spacing and layout?
- When should a design system employ half-grid 4px increments instead of standard 8px steps?
